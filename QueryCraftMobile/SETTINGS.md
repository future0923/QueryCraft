# iPhone / iPad 设置

2026-10-27。只在连接页右上角提供“设置”；工作区不重复放置设置按钮。采用系统 inset-grouped 分类列表和原生二级表单。浅色使用系统分组背景，深色基础画布为不透明纯黑；原生开关开启色为系统绿色。

| 分类 | 可设置内容 | 生效范围 |
| --- | --- | --- |
| 外观 | 跟随系统／浅色／深色、表格等宽字体与 11～18 pt 字号 | 应用外观；公共数据表格字体，不改用户编辑器配色 |
| 编辑器 | 字体、明暗主题、语法颜色、缩进、接受补全键、格式化大小写、主题导入导出与配色撤销 | 复用现有 MobileEditorPreferences 和 Mac 的规则／主题文件模型；保留可用的当前 SQL 连接高亮选项 |
| SQL 片段 | 新增、编辑、删除、恢复默认 | 复用当前设备的 SQLSnippetStore，沿用编辑器现有来源 |
| 表格与记录 | 默认每页 25／50／100／200／500 行；交替行背景；表头和记录详情的类型＋注释；自动时间戳；NULL 和空字符串显示 | 默认分页用于新建 MySQL／PG／Doris 浏览器与 ES 工作区，当前／恢复页面保留自身设置；显示设置即时更新公共表格，保留有效滚动、选择及手动列宽 |
| 导出 | CSV 字段名／NULL／BOM／分隔符／换行／引号／公式保护；JSON 布局／缩进；XLSX 表头／冻结／筛选；SQL INSERT 批量／事务包装／限定表名 | 复用 Mac WorkspaceDataExportPreferences；新任务捕获默认值，任务内调整不回写全局；无效批量输入保留最后有效默认值 |
| 关于 | 版本、构建 | 读取实际安装包信息 |

表头类型与注释目前是一个组合开关，读取已验证字段来源的实际详情，不拆解拼接字符串猜测注释。记录详情有独立组合开关。显示设置不改变原值、协议查询、筛选排序、复制、写入或导出；显式指定的单列时间格式优先于自动识别开关。

六类驱动逐项评估：MySQL／PostgreSQL／Doris 共用 SQL 表格；Elasticsearch 共用文档表格及文件导出；Redis 保留键类型专属编辑、分页和原始字节／命令导出，不套用关系表分页与文件默认值；Kafka 尚无移动端入口。应用外观适用于所有现有移动页面。Doris 仍为只读，设置不开放写入。

桌面 Sparkle 更新、启动窗口、动态驱动安装、SSH 和 MCP 服务设置没有移动端对应实现，不显示空开关。移动端尚未全面本地化，因此不提供只改变少数文案的语言选择。SQL 超时／结果策略、Redis 自动类型批量等仍需统一执行链路后另行接入；本轮不提供不能生效的控件。

验证证据在 `.build/mobile-settings/`。Swift Testing 使用随机 UserDefaults suite；真实系统测试也使用 DEBUG UUID 所属的独立偏好域并在结束时清理，不修改用户设置。中间编译、锁屏、字号递归和运行器启动失败均保留，不能引用先前 781 项结果证明新设置已通过。

实际操作覆盖：仅连接页的设置入口；原生二级返回；开关关闭；明暗切换；既有 SQL 文稿及原始结果保留；真实终止／重启后设置恢复；从设置进入编辑器并打开系统主题选择器、取消返回。最后检查了两端明暗设置、恢复后的开关状态与原始时间戳结果截图。截图保留在 `.build/mobile-settings/preview/`；回执索引为 `.build/mobile-settings/FINAL_SUMMARY.json`。

两轮专属 MySQL 容器与卷已核对所有权后清理；DEBUG 偏好域已由 UI 清理启动清除。最终签名检查及普通空测试环境启动回执保存在最终目录；用户原有连接、钥匙串、偏好与草稿保持原数据。本轮按用户要求提交源码和验证记录，不发布，也不修改已安装 Mac 程序。
