# PostgreSQL iPhone / iPad 对齐清单

2026-10-24。本轮 PG 专用功能与模拟器验收已完成。以 Mac 真实入口、模型和驱动源码为基线；详细报告与真实边界见 [VALIDATION](VALIDATION.md)。

| Mac 链路 | 移动功能与验收 |
| --- | --- |
| PostgreSQLCatalog / LibPQ | 数据库/Schema/表/视图/物化视图、真实类型/来源/注释、同源模糊搜索/筛选/分页，保留已有行为 |
| SQL 会话 / 流式磁盘缓存 | 原写入/事务/保存点/多结果/取消/完整缓存导出保留 |
| QueryResultEditing / PostgreSQLDataMutation | 来源明确的单表结果编辑/删除；别名/重复投影/原始主键与大整数；表达式/关联/视图不伪造可编辑身份 |
| 完整缓存页编辑 | 自动提交、完整结果的当前页可编辑/删除，同一磁盘缓存保留其他页和完整导出；换页拒绝旧编辑器，默认值/计算值不伪造服务器重算 |
| PostgreSQLSchemaEditingProvider | 同一 provider/descriptor：字段、主键、索引、注释、IDENTITY、新生成列，暂存/删除/恢复/预览；已有生成列存储/表达式仍沿 Mac 不支持 |
| WorkspaceNewTableDraft | 当前物理 Schema、新表字段/索引、零字段表、实际服务器版本能力；不显示 MySQL 表选项 |
| WorkspaceTableAction | 同源重命名/删除/截断/清空/所有所属 serial/identity 序列重置或设置，完整预览与确认；截断保留序列 |
| 索引 / 结构 SQL | 原 Mac 索引目录及转换共享；读取已加载字段定义 SQL 快照并分享，明确其非完整约束备份的范围 |
| DataImportReader / Plan / Importer | 原 CSV/TSV/文本/JSON/JSONL/XLSX/XLSM/SQL INSERT 解析、磁盘快照、映射与整批事务；系统 Files 原生入口 |
| 导入保护 | 选项变更/重读失败不能用旧预览，执行前核对并锁定目标；错误/取消整批回滚；提交回执不明保留全工作区写保护，关闭重开不能重放 |
| LibPQ COPY | 原 FROM/TO transport 共享；COPY FROM 真实事务写入/回滚已验证。Mac 表文件导入实际用 INSERT 批次；使用 COPY 的跨连接迁移工作台是另一项通用能力 |
| 对象身份 / 生命周期 | Schema/table 独立传递，显式引号、点号和转义引号精确保留；普通旧名称保持旧输出。取消/过期响应/后台/草稿/安全锁与统一刷新接通 |

## 已完成验证

- 五库全量：iPad **694/0/1**，iPhone **695/0/1**。各一个旧 ES 环境依赖用例跳过，当前自有 ES 实库用例通过。
- 最新同源码 PG 专项：两端各 **80/0/0**，包括最终缓存旧页守卫、零字段表和所有原生入口。
- Mac 共享导入/编辑/新表/表操作 **58/0/0**，缓存/删除/检查器 **18/0/0**，PG 驱动原测试 **13/0/0**。
- 最新 arm64 构建通过；PG 动态产品独立构建、隔离签名包与实际新包六类加载/真实特殊名称建表、索引元数据、大整数查询通过。
- 两端原生明暗/滚动确认画面检查完成。测试只操作脚本创建的临时数据库，结束删除；未操作用户数据库或已安装 Dev。

## 六类驱动影响

PG 提取原索引元数据/字段定义转换与事务结构 executor，两端共用；Driver API5和公开存储布局不变。新 PG 包依赖新增 host 身份符号，正式发行须配套最低主程序版本及双架构门槛，当前本地验证包不发布。

MySQL 原默认表单/表选项/分别提交 DDL/导入严格模式保留，共享缓存删除改为逐 payload SQLite 压缩；Doris 不新增写入；Redis/ES 沿专用链路；Kafka没有移动传输新增，仅验证现有桌面包兼容。五库全量及全部六类实际包加载核对相应影响。

## 明确边界

活动 SQL 事务、未完成缓存、临时表和复杂来源的图形结果编辑保持独立写连接/真实来源限制。数据编辑按主键定位，与 Mac 一样没有原字段值 CAS；并发修改可能覆盖。已有生成列、服务器权限、扩展类型按实际能力处理，缺失元数据不伪造。

通用跨连接迁移工作台、多文稿持久工作区和完整编辑器设置尚未迁移。真机触控、完整外接键盘/IME、真实挂起/弱网及更多 PG/TLS/证书组合未实测；模拟器和故障注入不代替这些验收。

代码在 codex/ios-ipad-editor 分支，本轮按用户要求纳入本地功能提交；不推送、打 tag 或发布。
