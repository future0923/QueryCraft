# QueryCraft iOS / iPadOS 移植验证

这是独立 worktree 中的 iOS / iPadOS 工程，最低系统版本 18。MySQL 保留已有完整移动功能；PostgreSQL 支持 SQL 写入/事务、磁盘缓存及查询结果编辑、表结构/新表/表操作和多格式文件导入，Redis 支持键/成员管理、搜索分页、Stream 浏览及命令事务控制台，Doris 支持只读流式 SQL、磁盘缓存和真实结构信息，Elasticsearch 接入完整专用工作区，具体范围见下文。直接共享现有模型与原生驱动源码，尚未达到桌面版全部功能。


当前能力以本节各驱动条目及最新验证记录为准；后文保留的历次移植阶段说明属于历史记录，其中旧的“只读／未移植”不覆盖当前范围。

完整真机测试、系统交互及未完成边界见[完整真机验证](FULL_PHYSICAL_VALIDATION.md)。

iPhone / iPad 的连接页提供原生设置入口：外观、编辑器、SQL 片段、表格与记录、导出及关于。具体生效范围与验证记录见[移动端设置](SETTINGS.md)。

按仓库AGENTS规范，深色页面及目录分栏基础背景使用纯黑；SQL、Redis、Elasticsearch目录共用基础画布规则，避免横屏/iPad侧栏的系统elevated灰底。只改基础背景，不借此调整按钮、图标、文字、选中态、输入框或编辑器主题。iOS/iPadOS开关单独使用系统绿色开启色和原生Switch，显式button样式的Toggle仍保留按钮；Mac浅色原有颜色和材质保持原样。

## 工作区新增能力（2026-10-25）

MySQL、PostgreSQL、Doris 的 SQL 页支持独立多文稿、重命名、保存查询及重启恢复；通过标题菜单管理文稿。每篇保留独立会话、事务、结果、数据库和 PostgreSQL Schema 列表，关闭活动事务先回滚，关闭未保存文本确认精确版本。恢复文件不含密码、查询结果或服务器事务，不自动重放 SQL。写入前保存待核实标记；未知结果在重启后继续保护。存储损坏不会被空文稿覆盖，可先备份、导出原文件再恢复保存；连接切换落盘失败会保留工作区。

首页“数据迁移”复用 Mac 的完整配置、catalog/planner/runner/manager、任务库和原驱动 session。源支持 MySQL/PG/Doris，目标支持 MySQL/PG；结构/数据、追加/覆盖/Upsert/重建、筛选、大小写、所有者、批量和超时按真实能力开放。完整 SQL 预览、解锁确认、进度/取消/备份、待核实运行记录及任务文件夹管理都有原生入口。COPY/LOCAL INFILE 使用原传输；不支持时按共享规则回退，不另建简化迁移器。修改连接不会丢弃未保存任务或使用旧密码提交。

连接页的“设置 → 编辑器”可调整：字体、两套主题、颜色、缩进、补全键、格式化大小写、配色撤销/恢复及主题导入导出均共享 Mac 规则。UIKit 原生选区、撤销、IME 和查找保留；行号与当前行装饰不切换 TextKit 模式。系统查找颜色、多光标和真实设备验收边界见 [WORKSPACE_PARITY.md](WORKSPACE_PARITY.md)。

## 新增驱动范围（更新至 2026-10-25）

连接表单可选 MySQL、PostgreSQL、Doris、Redis、Elasticsearch，旧连接文件缺少驱动字段时仍按 MySQL 解码，连接 ID 和钥匙串键不变。连接摘要显示驱动类型；切换驱动使用对应端口和认证/TLS 默认值。PostgreSQL 支持数据库和默认 Schema 配置。Kafka 的传输/消费链路尚未移植，表单不提供 Kafka 连接选项。

- **PostgreSQL**：直接编译 macOS 的 libpq 客户端、真实类型/字段来源转换，共用 `PostgreSQLCatalog` 的目录/字段/筛选逻辑及 `PostgreSQLDataMutation` 的行 SQL/事务批次。支持数据库、Schema、表/视图/物化视图、字段注释、分页/排序/筛选、共享模糊搜索和实际 Schema 的查询历史。物理 Schema/表名分别保留，点号和引号按单个标识符引用；别名/关联/表达式/空结果均按协议来源处理，注释不按显示名称猜测。
  SQL 控制台复用 MySQL 已有的执行范围、确认、安全锁、多结果、事务/保存点/提交/回滚、取消和后台断开状态。同一连接保留跨次执行的会话；自动提交下读取使用只读事务，显式事务内读取使用当前事务。支持 DML/DDL 和 RETURNING；错误时停止后续语句、关闭会话并回滚未提交事务，结果不明禁止自动重放。libpq 单行模式配合公共分批通道写入同一磁盘缓存，当前页最多 500 行/4 MiB，单行 8 MiB、整批缓存 256 MiB；分页和全部缓存导出不重执行 SQL。字段类型/来源在完整响应后于原连接解析，保留事务临时表信息；缓存分页继续保留 Schema 和注释。加载途中尚未解析的字段元数据为空，不伪造。
  表数据增删改沿用暂存、安全锁、SQL 预览、提交/撤销入口，事务内锁表并复查字段/主键。支持默认值、NULL、identity 默认新增和原始大整数主键；生成列不可直接编辑，无主键表不可修改/删除已有行，视图表格保持只读。bytea 沿桌面文本表示；NUL 文本明确拒绝。目录/表预览仍使用独立只读连接与有界结果，和 SQL 持续会话分开。查询结果可编辑来源明确的单基础表字段和删除行，复用 Mac 的目标/主键验证；别名、重复投影和大整数按真实协议来源处理，表达式/关联/视图不伪造可编辑身份。完整、自动提交的多页磁盘缓存也能编辑当前页，提交后更新同一缓存，保留其他页和完整导出；删除通过 SQLite 逐行压缩位置，不把整个结果读入内存。活动 SQL 事务、未完成缓存和不能解析唯一基础表的结果保持明确限制，临时表元数据不会冒用其他会话的同名对象。
  图形结构编辑直接共用 PostgreSQLSchemaEditingProvider、descriptor 和事务 executor；支持字段/主键/索引、注释、IDENTITY、新建生成列及删除/恢复暂存。实际 server_version_num 决定能力，不显示 MySQL 字符集、前缀索引、可见性或表选项；已有生成列的存储/表达式不能直接修改。新表使用当前物理 Schema、同源草稿/字段/索引和完整 SQL 预览；全部结构语句在独立 PG 事务内执行，发送前锁表并核对基线。表菜单支持重命名、删除、截断、清空和实际所属 serial/identity 序列重置/设置；截断保留序列，所有危险操作仍需确认和安全锁。
  表菜单「导入数据」使用系统 Files，直接共享 Mac 的 CSV/TSV/分隔文本、JSON/JSONL、XLSX/XLSM 和 SQL INSERT 解析器、冻结磁盘快照、字段映射、默认/生成列规则与事务执行器；可调整编码/行范围/NULL/工作表、查看文件预览和首行 SQL 示例，执行使用完整值。选项变更或读取失败不能提交旧预览；每批500行为默认值，可在1～10000调整，整份导入同一事务，中途失败/取消回滚。COMMIT 回执不明时保留全工作区写保护，只允许明确核对后结束，不能重新打开后重放。Mac 表文件导入实际使用 INSERT 批次；已共享 LibPQ COPY FROM/TO，其中 COPY FROM 已做真实事务回滚测试，跨连接迁移工作台现在直接使用原 COPY/LOAD DATA 与共享执行器。
  SQL 补全显示名称无法唯一反解时不猜物理字段。真实 TLS/证书、多版本服务器和实体设备场景仍待验收；当前本轮验收状态见 [POSTGRESQL_PARITY.md](POSTGRESQL_PARITY.md)。
- **Doris**：沿 macOS 的只读能力，复用 MariaDB 原生传输、SQL 编辑器、当前语句/选区、多结果、表/视图目录、列注释、分页、排序与筛选。Doris 与 Mac 共用 `DorisSchemaMetadata`，旧版本信息模式缺字段时回退 `SHOW FULL TABLES`。不发送 MySQL 的 `SET SESSION TRANSACTION READ ONLY` / `START TRANSACTION`，不开放事务、表/结构编辑与写 SQL。DUPLICATE/AGGREGATE KEY 不冒充唯一行标识，分页明确提示顺序限制。表数据页保持有界预览；SQL 页接入同一背压流和磁盘缓存、缓存分页及完整缓存导出。结构页读取原始 SHOW CREATE TABLE/VIEW 与共享索引转换；服务器不支持索引目录时明确提示不可用，不伪造空列表。CSV/JSON/XLSX 与 SQL INSERT 导出共用原写入器，SQL 使用 Doris 方言并省略事务包装。
- **Redis**：iPhone/iPad 接入与 Mac 共用的键搜索/前缀树、集合读取/搜索、编辑计划、二进制编解码、命令控制台和命令导出源码。支持 ACL 和逻辑库；目录默认包含匹配，也可选前缀/精确及 Redis glob，SCAN 可继续扫描，COUNT 是提示。属性读取真实 TYPE/PTTL、MEMORY USAGE、OBJECT ENCODING；无权限的可选元数据标为不可用。
  String 按 64 KiB GETRANGE 浏览，整值编辑沿 Mac 的 **100 MiB** 上限；文本/HEX/JSON 展示、原始字节与整键命令导出均保留完整值。大文本以约 32 KiB 的 UTF-8 安全片段展示，提交校验完整原值并写完整值，不拿预览覆盖原值；JSON 展示不改原始字节，格式化输出限 100 MiB。集合支持 list/hash/set/zset 增删改、List 头尾插入、选择/批量删除/所选命令导出，超过 1,000 项按页编辑；页请求 200 项，每页最多保留 1,000 项/1 MiB。全键成员搜索共用 Mac 的字段范围、包含/前缀/精确、大小写与变音符号规则，不局限当前页。ZSet 默认降序，List 保留实际绝对索引；有草稿时禁止翻页/换搜索。
  新建五种常用类型、RENAMENX 重命名、整键 TTL/PERSIST/删除；独立整键操作也适用于大集合和 Stream。Hash 字段 TTL 按实际 HPTTL 能力探测，支持读取、设置、移除，旧服务降级；改值沿 HSET 清除字段 TTL，重命名按剩余 TTL 时长重新计时。Stream 共用 Mac 的 XRANGE 解析，按实际 entry ID 继续浏览，通过控制台执行 XADD/XDEL 等写命令。
  命令控制台共用 Mac catalog/tokenizer/history/completion，支持 SELECT、WATCH、MULTI/EXEC/DISCARD 的同连接会话；已知读取命令可直接执行，写入和未知命令先解锁、预览、确认。输入每条限 1 MiB，历史限 1 MiB，记录限 4 MiB，大回复明确保留前缀，单条显示最多 120 行；这些是 UI 保留预算，非协议解析内存硬上限。后台上锁并关闭连接，未 EXEC 的事务丢弃；已发命令等真实回执。写入未知结果禁止直接重放，必须重新连接、读取核实；核实不推断原写入成功。
  所有图形写入沿共享 WATCH/原值断言及精确草稿确认，新建使用缺失断言防并发覆盖。刷新失败保留内容，取消/切换/后台隔离旧响应。新建内容限 1,000 成员/1 MiB，新建/重命名键名限 64 KiB。部分集合页不可冒充完整快照操作整键或整键导出，整键 TTL/删除走独立明确入口。二进制集合成员与 Mac 一样只读，可保留原字节导出；非 UTF-8 键名显示 HEX，不用有损别名操作。模块类型内容、TLS、MOVED/ASK 集群路由未支持；集群直连沿 Mac 仅 DB0。SCAN 不是稳定快照；原值比较不是持久版本，TTL 不作并发版本断言。
- **Elasticsearch（2026-10-24）**：直接编译 Mac 的完整 `ElasticsearchWorkspaceSession`、HTTP/认证/TLS/重定向限制、Mapping/Field Caps、筛选翻译和文档/Mapping 修改源码。索引、Alias、Data Stream 原生分组浏览，显示真实统计和健康，复用完整目录模糊搜索。数据页支持 25/50/100/200/500 条、按实际可聚合字段排序、filter/must/should/must_not 筛选；同源 PIT / search_after 支持超过 10,000 条的顺序翻页，旧服务器或 PIT 权限不足时沿 Mac 降级并明确限制窗口。刷新重新建立读取上下文和 PIT，保留已有内容；深页刷新无法直接定位时按共享规则回到首段，不冒用旧游标。超时或失败分片不当成成功空结果。字段类型只取真实 Mapping，冲突不伪造类型。
  文档支持真实 `_index` / `_id` / routing / version / seq_no / primary_term 检查器、新建、完整替换、局部更新、删除；单元格输入共用 Mac JSON 类型转换和 `CellChangesModel`，可跨文档暂存后统一预览/提交/撤销。CSV/TSV 多文档粘贴复用 Mac 表头和类型解析（最多 500 篇 / 8 MiB，每篇 1 MiB），当前页支持多选批量删除；每篇文档按版本条件操作，非事务批次出错即停，已收到的成功回执保留，禁止盲目重放。
  Mapping 支持嵌套/多字段新建与既有字段允许参数编辑，按逐段原始路径和真实基线检查，不改类型或伪装删除字段。新建索引支持分片/副本/初始 Mapping；删除仅允许重新核实的普通索引，禁止 Alias/Data Stream/backing index。索引设置/统计、动态副本和 refresh_interval、Alias 绑定/移除/write index/高级 filter 与 routing、索引模板新建/修改/删除、未来索引模板模拟均有独立原生入口，并直接复用 Mac worker 和基线核对规则。
  REST 控制台支持当前请求/完整选区/整篇文稿、NDJSON、多结果、同源格式化/DSL/方法/端点/字段补全、历史、表格/完整 JSON、诊断及原文未变时错误定位、后台任务读取入口。UIKit 编辑器保留选区/IME，iPhone/iPad 共用固定高度触控候选，外接键盘支持 Tab/Ctrl-Space/⌘Return；Mac 的路径补全算法抽为两端共用。刷新只重读捕获的读取请求，不执行编辑器里的写入。管理请求可转入控制台再次查看/确认，所有写入仍需安全锁和不可变完整请求预览。
  文档页和控制台沿用普通/全屏/记录/查找/检查器/列宽，CSV/JSON/XLSX 导出当前页；独立会话和 PIT 可按相同筛选排序分批导出全部匹配文档，不包含暂存修改。控制台可分享完整收到的 JSON 响应，不生成 SQL INSERT。后台取消读取、锁定、关闭 PIT/连接；重新进入创建新 HTTP 会话，不复用已失效 URLSession；已发送写入等待真实回执。不明结果仅允许只读核实和明确结束，ACL 核实失败继续保留保护。
  单响应保留预算 16 MiB，控制台一批保留回复 32 MiB、输入/历史各 1 MiB、表格显示最多 1,000 行（完整回复仍可分享）；检查器编辑限 1 MiB，超限明确只读预览，不将前缀当完整文档分享或保存。目录限 10,000 对象 / 8 MiB 名称。索引删除/设置/Alias/模板的基线复核不等于协议原子 CAS；Data Stream 通过真实 backing index 修改文档，安全限制沿 Mac。设备实触、外接键盘全矩阵、真实弱网/系统挂起及更广 TLS/服务器版本仍需独立验收。

ES 当前功能矩阵见 [ELASTICSEARCH_PARITY.md](ELASTICSEARCH_PARITY.md)，最新实际验证见 [VALIDATION.md](VALIDATION.md)。Redis 保留原当前页 CSV/JSON/XLSX 与专用原始字节/命令导出。

四类新增驱动页面均沿用当前顶部公共刷新入口、固定底栏加载/错误、表格查找/全屏/检查器及列宽状态；刷新保留已有内容，切对象隔离旧数据，取消及过期响应不能覆盖当前对象。Redis 的搜索框按所选包含/前缀/精确模式生成 MATCH，键盘搜索或顶部刷新应用；Elasticsearch 名称搜索在完整有界目录内本地匹配。目录最多保留 10,000 个对象/8 MiB 名称数据，HTTP 响应最多 8 MiB；这些是读取/保留预算，不是整个进程内存硬上限，hiredis 解析单个响应仍有额外分配。

## 当前 MySQL 范围

- 首页只显示已保存的连接与一个添加入口；进入连接后使用原生「表 / 查询 / 视图」页签，数据库选择保留在各页顶部。iOS 26 使用系统 Liquid Glass 标签栏，iPad 常规宽度采用侧栏标题菜单和对象分栏。返回首页后重新打开当前连接会保留草稿和已加载结果。
- 原生 MySQL 连接管理，连接配置原子保存；密码可选存本机钥匙串，关闭记住后仅驻留当前进程。
- 数据库选择、分别搜索表或视图。直接共享 macOS 的 `CompletionLabelMatcher` 匹配与排序源码，支持 `admin_user` 被 `ad`、`amu` 等匹配；加载目录后本地搜索，不按每次输入发 SQL，也不只搜前 200 个对象。目录元数据上限 10,000 个对象 / 8 MiB，超过时明确报错，不伪装成完整目录。
- 表数据每页 25/50/100/200 行，前后翻页、按字段排序；默认按主键排序，无主键会明确提示跨页顺序不稳定。
- 表/视图顶部「… → 筛选数据」支持整个对象的服务端筛选，复用 Mac 的条件模型、类型/运算符、默认值与 MySQL 谓词生成源码；支持全部/任一匹配、启用/禁用、范围及 NULL 条件。标签固定在左，输入值在右；取消保留原条件，应用回到首行，刷新/翻页保留条件。SQL 自定义查询结果仍使用当前已加载数据查找。
- 原生分组结构页与系统导航（紧凑宽度 Glass 页签、常规宽度侧栏标题菜单）。数据页默认表格，点顶部表名切换数据/结构；显示方式、查找、排序和页大小收进顶部菜单。手机表详情隐藏主导航，返回目录后恢复；常规宽度分栏通过左侧标题菜单切换表/查询/视图，不另占一行。底部行数与翻页共享一行，不再叠加浮动操作条。
- SQL 的当前语句、完整选区和整篇文稿执行／取消、多结果切换、按连接与数据库保存最近 50 条成功查询历史。原生 SQL 编辑框共用 Mac 的语法解析/高亮、上下文补全和排序；支持别名、关联/子查询/CTE 范围，真实表/视图/字段元数据按需读取。接受普通关键字、表名或字段后自动补齐／复用空格，并显示同一共享引擎生成的下一步候选；函数括号、库名限定和片段光标不擅自推进。iPhone 候选栏随键盘出现；iPad 完整软键盘上方使用固定高度的大触控候选卡片，可横向滑动，使用不透明明暗底色及顶部分隔线，等待补全时键盘位置保持稳定。iPad 外接／浮动键盘使用光标附近的纵向候选浮层，自动避开键盘。两种方式都可点选或用 Return/Tab 接受，外接键盘支持 Ctrl-Space、上下选择和 Escape，⌘ Return 执行。
- SQL 使用共享的分批传输与 Mac GRDB 磁盘缓存，当前缓存页最多 500 行／约 4 MiB，单行最多 8 MiB；缓存翻页不重新执行 SQL。整批编码缓存载荷最多 256 MiB（SQLite 页和 WAL 有额外开销），超限保留部分缓存并明确停止。表页仍最多 200 行／8 MiB。
- UIKit 双向虚拟表格、固定表头、抽样自动列宽、拖动列宽与本机保存；长文本轻量预览、单元格/整行详情（长文本有明确预览上限并可分享全文）、NULL/空字符串/二进制预览、当前已加载结果内查找。
- 顶部「… → 全屏表格」可纯表格浏览当前已加载页或查询结果，隐藏导航、侧栏、编辑器和分页栏。退出按钮约 2 秒后收起，轻点表格重新显示；支持 Escape 和辅助功能退出。退出时恢复滚动位置、列宽与选择，不重新查询。
- 全屏内容遵守设备安全区，竖屏/横屏滚动时表头和单元格避开灵动岛；仅背景延伸至屏幕边缘。打开表时清除目录搜索焦点，进入全屏时收起数据查找/SQL 编辑器键盘，全屏窗口在尺寸变化和残留键盘请求时清除输入焦点。退出后仍可正常搜索、编辑。
- 普通/全屏的表页和 SQL 结果均按起始主方向锁定单次拖动及惯性，避免斜向漂移；新手势可切换方向，普通数据格不拦截列宽拖动手势。
- 「… → 查找当前已加载数据」复用 Mac 查找逻辑，支持按列、包含/等于/开头/结尾、区分大小写与上/下一个匹配定位，保留全部行。查找条的选项菜单可调整条件，键盘按钮可先收起键盘，随后关闭查找。SQL 结果查找时编辑区暂时收起，结束后保留草稿恢复；iPad 支持 ⌘F / ⌘G / ⇧⌘G。
- 唯一顶部公共刷新按当前页面派发；加载和失败保留已有数据与滚动位置/列宽，固定底栏提示进度和错误；切换数据库或表立即隔离旧数据，拒绝过期响应。
- iPad 分栏和表格；iPhone 层级导航与表格，两端可从顶部菜单切换记录摘要及整行详情。UI 参考 TablePro 移动端的信息层级，最低 iOS / iPadOS 18。

读取查询在无活动事务时使用服务端只读事务；写 SQL／DDL 通过安全锁和完整 SQL 确认执行，UPDATE／DELETE／DROP／TRUNCATE 使用 Mac 同源分类规则。SQL 会话支持跨执行事务、保存点、提交／回滚和断开，状态来自服务器；后台关闭连接并回滚未提交事务，不自动重放写入。尚未移植完整桌面编辑器（多光标、自定义配色等）、导入、选中范围导出和全部工作区功能。

## 构建

需要 Xcode 26.2+、XcodeGen、CMake 3.31+ 和 XcodeBuildMCP。运行模拟器还需要在 Xcode Settings → Components 安装 iOS runtime。

从仓库根目录执行：

```sh
# 如果没有 CMake，可仅安装到忽略的工作目录，不修改系统环境。
python3 -m pip install --target .build/ios-tools cmake==3.31.6
bash scripts/build-ios-mariadb.sh
bash scripts/build-ios-libpq.sh
xcodegen generate --spec QueryCraftMobile/project.yml
xcodebuildmcp simulator list
xcodebuildmcp simulator build-and-run \
  --project-path QueryCraftMobile/QueryCraftMobile.xcodeproj \
  --scheme QueryCraftMobileProof \
  --simulator-id '<iPad simulator UUID>' \
  --derived-data-path .build/ios-proof-derived
```

可通过 `CMAKE_BIN` 指定已有 CMake，通过 `IOS_BUILD_JOBS` 限制并发。两个原生库脚本均可按平台/架构构建，传入 `iphonesimulator x86_64`、`iphonesimulator arm64` 或 `iphoneos arm64`。

OpenSSL 3.6.3、MariaDB Connector/C 3.4.9 与 PostgreSQL libpq 18.6 沿用仓库现有版本和 SHA-256 校验值，从上游源码构建；库、构建工具和日志全部写入 `.build/`。发布前需要单独评估依赖版本、许可证与签名。真机工程目前关闭签名，安装真机需要配置自己的开发团队和签名设置。

## 共享方式

`project.yml` 的 `QueryCraftMobileCore` 直接编译已有 Foundation 模型、错误、事务状态和流类型；`QueryCraftMobileTransport` 直接编译现有 MariaDB 传输源码；移动应用直接编译原 libpq 客户端。`MobileSQLConfiguration` / `MobileSQLPreview` 只适配移动端的配置和结果边界，保留 PostgreSQL 的完整 Schema 来源，不修改桌面传输的公开 ABI。没有复制或重写数据库协议，也没有引入 TablePro 源码或预编译库。

桌面端依然将这些类型编入 `QueryCraftFeature`，保持原模块中的名义类型身份。三个仅依赖 `WorkspaceSession` 的能力协议移到同一 Feature 模块的独立文件，便于将可移植流实现单独编译。Driver API 和版本号未改动。

这是用于确认可移植边界的源码共享方案。正式移动版应进一步设计共享核心包与桌面驱动兼容迁移，不应把全部桌面 Feature 依赖直接引入 iOS。

SQL 编辑器右上方的「{}」打开代码片段管理，可新增、编辑、启用／停用、删除及恢复默认片段。输入 `sel`、`cte`、`join` 等缩写后选择片段，即可展开完整模板；`${名称}` 会成为待填写位置。编辑器上方的箭头切换上一项／下一项，最后一项的勾号结束填写；外接键盘支持 Tab、Shift-Tab 和 Escape。使用 Mac 同一份模板、匹配、占位符与持久化逻辑，内置 11 个片段；自定义片段各设备本地保存，目前不自动同步。写操作模板不会绕过现有只读 SQL 执行限制。

完整的 Mac 优化同步清单见 [MAC_PARITY.md](MAC_PARITY.md)。SQL 结果只显示协议真实类型和来源；表数据注释依据完整的 database/table/column 来源匹配，表达式和其他来源不猜测补全。

移动端采用有界查询和表分页，已支持多个语句结果切换；尚未移植 Mac 的大结果磁盘缓存和增量结果流。4/8 MiB 是保留的原始字段字节预算，不是整个进程内存硬上限：字符串、数组、元数据和单个传输包仍有额外开销。首次开表先读取字段再读数据；还没有移动端连接池或内存压力恢复。

支持关闭 TLS 或要求加密；不提供 verifyCA/verifyIdentity。Connector/C 3.4.9 在 `plugins/auth/my_auth.c` 对 loopback 地址跳过部分 CA/主机名检查，仅设置 `MYSQL_OPT_SSL_VERIFY_SERVER_CERT` 不能承诺严格身份验证。后续仍需 CA 证书配置和严格校验；本次不改变已发布桌面驱动的 TLS 行为。

实际构建、测试、截图与尚未验证项目见 `VALIDATION.md`。

时间戳显示与 Mac 共用格式化源码：自动识别数值时间字段，长按表头可逐列选择「自动识别 / 原始值 / Unix 秒 / Unix 毫秒」。普通和全屏表格共享选择；表刷新保留格式，新 SQL 结果重置。单元格详情、分享和查找使用原始值。

筛选输入时，点击键盘右下角「完成」可收起键盘并保留草稿；右上角「应用」才会执行筛选。

## 数据导出

表/视图数据页「… → 导出数据」可选择「当前表页 / 全部匹配数据」，生成 CSV、JSON、Excel（XLSX）或 SQL INSERT，通过系统「文件」面板存储。默认仍是已加载页；全部匹配数据从首行开始，固定使用打开导出时已成功页面的筛选、排序、对象和连接，分批读取并显示进度，可取消、失败后重试，支持视图和空结果。SQL 查询结果「… → 导出已加载数据」仅保存已加载的预览，若截断会明确标注，不自动重新执行 SQL，也不执行导出的 INSERT。

格式、字段名、NULL、CSV 编码/分隔/换行/引号/公式保护、JSON 布局、Excel 表头、SQL 批量/事务选项直接使用 Mac 的导出模型/默认值；更多选项放在可展开的「文件选项」中。时间戳采用原始值，长文本不使用网格截断预览。二进制在 CSV/JSON/XLSX 中仅导出字节数说明，SQL INSERT 不支持二进制，与当前 Mac 保持一致。查询 SQL 导出须指定目标表。

生成期间可取消，取消保存面板后可重试；关闭导出页清理临时文件。整表沿用 Mac 的分批行源及写入器，移动端每批最多 200 行 / 8 MiB 原始字段字节，最多预取下一批；单批超限明确失败，不生成截断文件。系统 Files 直接接收文件 URL，应用不把整份输出读进 FileWrapper。此上限不是整个进程的内存上限。与 Mac 的分页语义一致，服务器并发写入可能影响跨批次结果，未承诺事务快照；无主键的顺序仍可能不稳定。选中单元格范围、任务中心和导出偏好持久化尚未移植。

## SQL 编辑器

移动编辑框采用原生 UITextView，直接编译桌面 SQLStructuralParser、SQLCompletionEngine/Ranker、语法与恢复规则、默认明暗配色。输入中文时保留 marked text，不套高亮、不插入补全、不重载键盘；选中范围、UTF-16 光标、滚动和原生撤销保留。长 SQL 仅给可见区域应用颜色，解析在独立 actor；高亮不改写 SQL。

表/视图目录和字段使用 MySQL 驱动同一查询及转换源，包含真实类型、序号与注释，不按同名字段猜来源；只有当前查询范围所需的字段才加载，已离开范围的字段缓存释放，相同进行中请求合并。切换连接/数据库、修改密码、快速输入和取消时拒绝过期结果。元数据失败不影响编辑/已有查询结果，仍可使用关键字；输入框旁提示元数据异常，公共刷新/重新执行后可重试，Ctrl-Space 也可重新请求。

SQL 内容区现有小键盘图标可以收起键盘，键盘 Return 保留 SQL 编辑语义（候选可见时接受候选，否则换行）。输入法组合期间 ⌘ Return 仅结束组合，不执行 SQL。执行入口使用 Mac 同一份当前语句定位和选区预检：可运行光标所在语句、所选完整的多条只读查询，或从播放按钮菜单执行整个文稿；整批先验证，不开放 SQL 写入和事务控制。代码片段管理与占位符会话已接入同源实现；自定义配色设置、多光标等完整编辑器功能仍未移植。

语法依赖固定为与当前 Mac 相同的 SwiftTreeSitter 0.25.0 / tree-sitter 0.25.10；SQL grammar 与高亮资源来自仓库本地 CodeEditLanguages。重新生成工程后由 Xcode SwiftPM 获取依赖，不引入 AppKit 编辑器到 iOS。


## MySQL 表数据编辑

普通表格点单元格进入原生编辑表单，值靠右，支持原始文本、NULL 与字段默认值；键盘右下角“完成”仅收起键盘，点“暂存”才加入待提交内容。修改单元格标黄，暂存删除的行标红并保留原位置。底部原有状态栏的铅笔按钮或顶部“待提交改动”打开 SQL 预览，可以统一提交或撤销；“新增行”及“暂存删除／恢复选中行”在现有顶部菜单，编辑单元格里也可暂存删除这一行。暂存新增行可以在预览里重新打开修正，长按该项可撤销这条新增。

安全锁沿用 Mac 默认开启，提交前可在预览中解锁；写入使用绑定参数，按原始主键合并同一行的字段，保留长整数精度，不使用格式化时间或修改后的主键作 WHERE 条件。多条删除、修改、新增共用一次事务，失败保留草稿。草稿按当前连接的对象保留，跨页、筛选、刷新、返回首页仍在；回到原表才能提交。存在待提交改动时，更换/删除连接会被阻止，避免无提示地丢失草稿。应用退出后不持久保存暂存改动。

当前范围为 MySQL InnoDB 真实表；视图身份和复杂 SQL 查询结果仍为只读入口；全屏与记录详情沿用相同字段编辑限制。没有主键的表不能修改/删除；生成列和仅保留预览的二进制值不能编辑，完整二进制编辑未支持。新增的未填写/默认值字段沿 Mac 规则交由服务器处理，字段类型和约束由服务器最终校验。非事务引擎明确拒绝，不声称可以回滚。与 Mac 当前规则一致，更新按主键匹配，不对原字段值进行乐观并发比较；外部修改可能被覆盖。提交结果无法确认时阻止重复提交，需核对服务器后丢弃草稿并刷新，不能自动重放写入。

## SQL 查询结果编辑

执行来源明确的单表 SELECT 后，轻点结果中的真实字段即可使用同一原生编辑表单；结果菜单支持暂存删除/恢复选中行，不提供新增行。现有状态栏的铅笔按钮打开待提交预览，默认安全锁与表页共用，确认 SQL 后解锁提交。别名、跨数据库和复合主键按协议原始来源/原值处理；表达式、生成列、二进制预览和缺失主键保持只读，不根据显示名称猜字段。

暂存期间刷新/重新执行、切换查询数据库、更换或删除连接会提示先提交/撤销；切换页签和返回主页保留同一份暂存，返回主页重新启锁。提交成功直接更新当前结果中的物理字段并移除已删除行，保留 SQL 草稿，不自动重跑查询；同一物理字段的重复投影同步显示，计算表达式/生成值需显式重新执行才重新计算。使用 DEFAULT 后，需重新查询实际服务器值才能继续编辑。导出使用已加载原始/已提交结果，不把未提交草稿写入文件。

本轮移动编辑只开放解析可靠且只有一处关系引用的查询；关联、自关联、嵌套查询/复杂 CTE 以及解析不可靠语句保持只读。MySQL 来源元数据不保留关系别名，不能把 a.id 与 b.name 冒充为同一原始行。中文别名建议使用反引号（例如 AS `名称`）；解析器不支持的合法语法仍可读，不冒充已对齐所有 Mac 查询编辑能力。SQL 文本执行仍只读，写入仅经过独立受控事务。

## 全屏和记录详情编辑

SQL 文稿中可以保留多条语句：没有选区时，顶部播放按钮或外接键盘 ⌘ Return 运行光标所在查询；选中完整的多条查询时按顺序执行所选内容。选区、注释和分号边界复用 Mac 的规则，未执行部分保留。顶部刷新重新读取当前结果实际执行的 SQL，不会因后来移动光标或编辑草稿改查另一条；暂存修改仍须先提交或撤销。播放按钮菜单或 ⌘⇧Return 可执行整个文稿。

表操作已支持与 Mac 相同的六项：重命名、删除、截断、清空、重置自增、设置自增值。长按目录中的表名，或在表数据/结构页右上角菜单进入。原生确认页展示数据库、表名、SQL 预览及操作说明；重命名以外的操作需完整输入表名确认，并通过同一个安全锁。自增页读取服务器当前下一值，提交前再次验证真实自增列。

## 多语句与多个结果

播放按钮轻点运行选区／当前语句，展开菜单可执行整个文稿；外接键盘对应 ⌘Return／⌘⇧Return。整批使用 Mac 同一份解析、定位、预检和顺序执行循环，先验证全部语句再执行，遇错或取消立即停止，保留已完成结果并标明后续未执行。当前只开放只读查询，一次最多 20 条、文稿最多 256 KiB；未知语句、任意写 SQL 和事务控制仍不执行。

同一批 MySQL 查询使用一个连接和只读事务，保留会话身份。每结果最多 500 行／4 MiB，整批最多保留 8 MiB 原始字段数据；预览截断会关闭未读完的连接，因此停止剩余语句并明确说明，需单独运行其余查询。预算不是进程内存硬上限；刷新时还会暂时保留旧数据。

点击「查询结果」旁的菜单切换；窄横屏可用顶部 SQL 查询标题菜单。每结果分别保存真实字段来源、注释、编辑草稿、网格滚动／选择／列宽和时间戳显示状态。加载保留上次选中数据并明确标注，成功后替换；失败、取消和未执行不冒充成功为空。顶部公共刷新只重读当前选中的语句，忽略后来改动的 SQL 草稿，不重跑先前成功语句。暂存修改仍须先提交或撤销；切换结果保留草稿，表／结构操作也检查隐藏结果的草稿。提交一个结果后，同表的其他旧结果需刷新核对。

历史按实际成功的每条 SQL 记录，切换结果不会制造新的执行记录。导出和检查器对应当前选中结果；尚未增加跨批次的 SQL 页签、持久工作区或磁盘结果缓存。


## 新建 MySQL 表

表目录底部现有状态栏右侧点「新建表」，在原生表单填写表名、字段、主键、索引和表选项。直接使用 Mac 的 WorkspaceNewTableDraft、结构编辑状态、表选项联动和 MySQL SQL 生成器。字段和索引使用已有结构编辑表单，支持类型、默认值／表达式、生成列、注释、可见性、字符设置及索引字段顺序。表选项包含引擎、字符集／排序规则、行格式、自增初始值、注释和四项高级选项；建议值来自服务器，具体版本／引擎限制由服务器校验。

## 已有表的选项编辑

在表页切换到「结构」，打开底部现有「字段／索引」菜单中的「表选项」。表单读取服务器真实引擎、字符集／排序规则、行格式、下一个自增值、注释和四项高级选项，与 Mac 共用数据转换和选项模型。输入值靠右，回车只收起键盘；点「暂存」后，选项与字段、索引进入同一份待提交结构草稿，点击已有底栏铅笔预览并通过安全锁提交。取消表单不修改草稿；撤销全部结构改动也恢复原选项。

暂存时不刷新覆盖草稿；先提交或撤销后，通过顶部公共刷新重读。读取失败保留旧值，刷新或切换对象后旧表单拒绝暂存；提交前核对已编辑选项的服务器值。成功后更新目录注释和当前对象身份；后续读取失败不重复执行 DDL。部分执行或回执不明仍须核对服务器后明确重新加载结构。当前仅 MySQL 表适用，视图无此写入入口；未开放外键设计或任意写 SQL，草稿不跨应用重启保存。


## SQL 大结果与写入／事务（2026-10-23）

默认安全锁开启；执行写语句时先展示捕获的完整 SQL 和数据库，确认后解锁并执行。确认期间编辑 SQL 或连接会使确认失效。允许写入后，UPDATE／DELETE／DROP／TRUNCATE 仍需确认。事务菜单位于编辑区已有的安全锁菜单；活动事务阻止更换连接／数据库及其他页面的独立写入。提交、回滚和断开均显式操作；进入后台或返回连接首页关闭 SQL 会话，未提交事务由服务器回滚。语法／权限等明确拒绝如实显示；中断写入或提交的未知结果会锁住后续写入，须核对服务器后手动解除。顶部刷新只重读 SELECT 等读取语句，绝不重放写 SQL 或 COMMIT。

查询结果使用 Mac 同一份 WorkspaceQueryResultStore 和导出行源，移动端立即落盘。完整 SQL 结果保留类型、来源、NULL／二进制描述与空结果字段；界面只加载一页。查找限当前缓存页，导出可覆盖全部缓存。大结果页及事务内结果保持只读；不超过 500 行且来源明确的单表读取仍可编辑，行编辑提交后不继续使用旧缓存。

释放结果时异步关闭并删除 SQLite／WAL／SHM；替换结果、清空结果缓存及退出进程后不保留工作区恢复数据。下次启动只清理本应用沙盒中上次运行的 mobile-* 缓存目录；导出窗口持有的缓存会保留到窗口／导出行源释放。临时缓存上限按每批编码载荷 256 MiB 控制；刷新保留旧快照期间会短暂同时存在两批，SQLite 页／WAL 另占空间。构建／测试产物属于开发目录，不属于运行时查询缓存。

当前仍未移植导入、移动非 MySQL 驱动、CA／主机名严格验证及全部 Mac 编辑器设置。二进制沿用网格语义只保存长度和 128 字节预览，不能当作无损备份；CSV／JSON／XLSX 导出描述，SQL 导出拒绝二进制值。
