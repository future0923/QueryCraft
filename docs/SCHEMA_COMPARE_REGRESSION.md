## 用户实测后的 MySQL 5.7 修复（2026-10-16）

先前回归遗漏了用户截图中已出现的 5.7 → 8.0。8.0 / 8.4 的成功不能代表该场景通过；原版本限制导致初始读取被拒绝，失败又被导航到空白结果页。

- 支持 MySQL 5.7 元数据，不再依赖 version_comment 必须包含 mysql；明确拒绝 MariaDB。
- 整数显示宽度除 ZEROFILL 外按展示差异归一化，保留字符串长度、DECIMAL 精度及真实类型差异。忽略只影响旧版 CREATE USER 的 NO_AUTO_CREATE_USER，其他 SQL 模式仍须一致。
- 处理 5.7 与 8.x SHOW CREATE 对隐含 utf8mb4 排序规则的不同呈现；真正的 general_ci / 0900_ai_ci 差异仍显示并阻止新增 SQL。
- 初次失败返回连接页面并给出一次原生错误提示，可重试或修改连接；刷新失败保留原结果。原生窗口标题不再使用被挤压的 principal 工具栏标签；统一工具栏生命周期与页面最小尺寸，避免下一步扩大窗口。
