# QueryCraft 0.1.5

## 本次更新

- QueryCraft macOS 客户端现已公开源码；当前所有功能均可免费使用，授权、试用到期和离线宽限状态不会限制现有功能。
- 新增完整的 Redis 工作区，支持逻辑库与 Key 浏览、五类常用值编辑、命令文档、补全，以及受 Safety Lock 保护的预览和提交流程。
- 新增 Elasticsearch 工作区，支持索引、文档、Mapping、Alias 和组合索引模板管理，并提供 REST 控制台、请求预览与大结果分页。
- 数据库驱动接口升级至 Driver API 3。本次同步发布 MySQL、PostgreSQL、Doris、Redis 和 Elasticsearch 的 Intel 与 Apple Silicon 原生驱动。
- 保留工作区恢复、连接切换、查询文档和数据网格状态，并继续通过 Sparkle 提供经过 Ed25519 验签的应用内更新。

## What's New

- The QueryCraft macOS client is now open source. All current features are free, and license, trial-expiration, and offline-grace states no longer restrict existing functionality.
- Added a complete Redis workspace with logical-database and Key browsing, editing for five common value types, Command Documents, completion, and Safety Lock protected preview and commit workflows.
- Added an Elasticsearch workspace with index, document, Mapping, Alias, and composable index-template management, plus a REST console, request previews, and paged large-result handling.
- Upgraded the database driver contract to Driver API 3. This release publishes native Intel and Apple Silicon drivers for MySQL, PostgreSQL, Doris, Redis, and Elasticsearch.
- Preserved workspace restoration, connection switching, Query Documents, and data-grid state while continuing to deliver Ed25519-verified in-app updates through Sparkle.
