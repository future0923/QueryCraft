# QueryCraft 0.1.4

## 本次更新

- 新增工作区连接切换器，可从标题栏搜索并切换连接；已有工作区会直接激活，新连接会在独立工作区打开，并支持 `Shift-Command-K` 快捷键。
- 优化数据库上下文切换和工作区恢复，及时取消已离开页面的数据任务，同时保留标签页、查询编辑状态和数据网格位置。
- 改进 macOS 15 的侧栏与内容标签导航，并重构工作区工具栏，使窗口缩放、侧栏展开和待提交操作时的布局更稳定。
- 暂存修改现在只将实际改动的单元格标为橙色；新增行继续整行显示绿色，删除行继续显示红色，表数据和可编辑 SQL 查询结果保持一致。
- 修复 SQL 预览无法通过工具栏按钮或 `Shift-Command-P` 打开的问题，并确保快捷键在中文输入法下正常工作。

## What's New

- Added a searchable workspace connection switcher in the title bar. Existing workspaces are activated in place, new connections open independently, and `Shift-Command-K` opens the switcher.
- Improved database-context switching and workspace restoration by canceling obsolete data tasks while preserving tabs, query editing state, and data-grid positions.
- Refined sidebar and content-tab navigation on macOS 15, and rebuilt the workspace toolbar for stable layout while resizing, expanding the sidebar, and staging changes.
- Staged updates now highlight only the changed cells in orange. Inserted rows remain green, deleted rows remain red, and the behavior is consistent across Table Data and editable SQL results.
- Fixed SQL Preview presentation from both the toolbar button and `Shift-Command-P`, including shortcut handling with Chinese input sources.
