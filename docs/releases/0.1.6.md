# QueryCraft 0.1.6

## 本次更新

- Redis 侧边栏新增“新增 Key”：选择 String、Hash、List、Set 或 Sorted Set 后打开草稿标签页，可编辑值、设置过期时间并预览将要执行的命令；创建成功后草稿标签页会替换为新建的 Key。创建同样受 Safety Lock 保护，需要时可在确认后停用。
- 数据网格支持点击列头选中整列，按住 `Shift` 点击可跨列扩展；查询结果、表数据和 Redis 集合网格行为一致。
- Inspector 面板默认收起，仅由工具栏控制显隐；手动拖拽收起会同步状态，上次调整的宽度会被记住并在后续窗口中恢复。
- SQL 批量执行预检现在接受“选区正好是某条只读语句前缀”的情况，按该只读语句执行，不再要求写权限。
- 驱动兼容性提升至 Driver API 4：旧版驱动与当前客户端不兼容，会被明确拒绝并提示更新；驱动安装目录按 API 版本隔离，避免不同版本互相加载或清理。本次同步发布基于 Driver API 4 的 MySQL、PostgreSQL、Doris、Redis 和 Elasticsearch 驱动，覆盖 Intel 与 Apple Silicon。
- 数据库连接支持用户配置的 HTTP 端点，TLS 仍由连接配置显式决定；连接测试失败时显示可读的错误描述。

## What's New

- Added New Key to the Redis sidebar: choose String, Hash, List, Set, or Sorted Set to open a draft tab where you can edit values, set an expiration, and preview the commands that will run. On success the draft tab is replaced by the created key. Creation is protected by Safety Lock, which can be disabled after confirmation when needed.
- Data grids now select an entire column when you click its header; hold `Shift` to extend the selection across columns. Query Results, Table Data, and Redis collection grids behave the same way.
- The Inspector starts collapsed and its visibility is controlled by the toolbar. Collapsing it by dragging syncs the state, and the width you last dragged is remembered and restored in later windows.
- SQL batch preflight now accepts a selection that is exactly the prefix of a single read statement as that read request instead of requiring write access.
- Driver compatibility is now Driver API 4: older drivers are incompatible with the current client, are rejected with a clear message, and prompt an update. Driver installs are separated by API version so different app generations cannot load or remove each other's drivers. This release publishes Driver API 4 drivers for MySQL, PostgreSQL, Doris, Redis, and Elasticsearch on Intel and Apple Silicon.
- Database connections accept user-configured HTTP endpoints while TLS remains explicit in the connection configuration, and failed connection tests now report a readable message.
