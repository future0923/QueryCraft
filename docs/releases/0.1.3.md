# QueryCraft 0.1.3

## 本次更新

- 重建工作区内容标签页，在 macOS 15 上也能稳定点击和切换，不再被标题栏拖拽区域阻断。
- 数据表、视图和查询文档使用独立标签页；切换时保留查询光标、未保存 SQL、数据网格位置和编辑状态。
- 支持拖拽调整标签页顺序、标签页关闭菜单、`Command-1...9` 数字切换，以及 `Command-Shift-[` 和 `Command-Shift-]` 循环切换。
- 优化标签页在浅色、深色及窗口失焦状态下的选中效果，并使用系统控件度量改善标签页高度。
- 调整工作区侧栏选择态、查询编辑器当前行高亮和底部操作栏背景，使内容层级更清晰。

## What's New

- Rebuilt workspace content tabs so clicking and switching remain reliable on macOS 15 without being intercepted by the titlebar drag region.
- Tables, views, and query documents now keep dedicated tabs, preserving the query cursor, unsaved SQL, data-grid position, and editing state while switching.
- Added drag reordering, tab close menus, `Command-1...9` numeric selection, and `Command-Shift-[` / `Command-Shift-]` cycling.
- Improved selected-tab visibility in Light, Dark, and inactive-window states, with tab height derived from native control metrics.
- Refined workspace sidebar selection, query-editor current-line highlighting, and the bottom action-bar background for clearer visual hierarchy.
