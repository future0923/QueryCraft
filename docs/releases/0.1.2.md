# QueryCraft 0.1.2

## 本次更新

- 查询结果现在支持直接编辑可明确定位到基础表和主键的单元格，并与数据页共用暂存、SQL 预览、放弃和提交交互。
- 查询编辑器的数据库选择器移至底部操作栏；PostgreSQL 可分别选择 Database 和 Schema，MySQL、Apache Doris 与 SelectDB 继续使用单一 Database 上下文。
- PostgreSQL 查询会在所选数据库的新会话中应用 Schema `search_path`，未限定 Schema 的 SQL 将按当前选择执行。
- 系统数据库现在始终显示；移除工作区“更多操作”菜单和对应设置，同时保留菜单栏中的工作区刷新命令。
- 修复 PostgreSQL 连接未设置默认数据库时，选择数据库后无法加载 Schema 和数据表的问题。
- 切换数据库时会先停止旧的对象加载，并在目标数据库连接就绪后再刷新对象列表。
- 数据库驱动接口升级至 Driver API 2，MySQL、PostgreSQL 和 Doris 驱动开发版本升级至 `1.0.2 (3)`。
- 数据库驱动改用多版本兼容目录；卸载后重新安装或检查更新时，会自动选择与当前应用、Driver API 和 Mac 架构匹配的最新版本，并在新版本下架后回退到旧兼容版本。
- 显著减小 macOS 安装包和数据库驱动包体积，移除发布产物中的测试插桩、覆盖率数据和本地调试符号。
- 调试符号改为独立保留，既减少公开下载体积，也保留崩溃分析能力。

## What's New

- Query results now support direct editing when a cell can be authoritatively mapped to a base table and primary key, using the same staged changes, SQL preview, discard, and commit workflow as Table Data.
- The query database selector now lives in the bottom action bar. PostgreSQL exposes separate Database and Schema controls, while MySQL, Apache Doris, and SelectDB keep a single Database context.
- PostgreSQL query sessions apply the selected Schema as their `search_path`, so unqualified SQL executes in the chosen context.
- System databases are now always visible. The workspace More Actions menu and its setting were removed while the workspace refresh command remains available from the macOS menu bar.
- Fixed an issue where PostgreSQL schemas and tables could not load after selecting a database when the connection had no default database.
- Database switching now stops stale object loading and refreshes the object list only after the target database connection is ready.
- The database driver contract is now Driver API 2, with MySQL, PostgreSQL, and Doris development drivers updated to `1.0.2 (3)`.
- Database drivers now use multi-release compatibility catalogs. Reinstall and update checks select the newest release matching the app, Driver API, and Mac architecture, and fall back when a newer release is retired.
- Significantly reduced the macOS and database-driver download sizes by removing test instrumentation, coverage data, and local debug symbols from distributed binaries.
- Debug symbols are retained separately for crash analysis without increasing public download sizes.
