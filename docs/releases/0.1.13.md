# QueryCraft 0.1.13

## 中文

- SSH 作为统一连接类型管理，支持分组、搜索、账号和跳板配置；原生 PTY 终端支持双向输入输出、窗口缩放、Ctrl-C、全屏程序、精细滚动和持续输出时的历史位置保持。SwiftTerm 显示组件随独立 SSH 插件按需加载。
- 增加本机 Shell 脚本库与复用入口，保留草稿、精确确认、修订冲突和凭据隔离。MCP 支持 SSH 命令、SFTP、任务与传输查询，服务器无需安装额外代理。
- 修复 MCP 权限继承和上下文函数的误拦截，按真实目标检查 SQL、Redis、Elasticsearch 和 Kafka 操作；范围、连接授权、工具开关与高风险确认仍分别生效。更新 Skill 的权限与错误恢复说明。
- 完善 SQL 字段来源、类型与注释、流式查询、磁盘结果缓存和导出；共享 MySQL/PostgreSQL/Doris 目录及元数据逻辑，完善 Redis 集合、字段 TTL 与 Stream 读取，保持原始值及未知写入结果保护。
- 深色基础背景统一为纯黑，保留原生控件及浅色外观。分栏保留各窗口布局身份、宽度和显示状态；统一 SSH 页面及设置入口。
- 源码同步包含 iPhone/iPad 多驱动工作区、数据迁移、编辑器与原生设置，以及真机验证工程。本次正式下载附件为 macOS，未包含 App Store/TestFlight 发行包。

## English

- Manage SSH through the unified connection catalog, including groups, search, accounts and jump hosts. Native PTY terminals support duplex I/O, resizing, Ctrl-C, full-screen applications, precise scrolling and anchored scrollback. The SwiftTerm renderer loads on demand from the independent SSH plugin.
- Add a reusable local Shell library with retained drafts, exact confirmations, revision conflicts and credential isolation. MCP provides SSH commands, SFTP, tasks and transfer queries without a remote agent.
- Fix MCP permission inheritance and excessive context-function restrictions. SQL, Redis, Elasticsearch and Kafka checks follow actual targets while preserving scopes, account grants, tool switches and high-risk confirmations. Update Skill guidance and error recovery.
- Improve physical SQL field origins, types/comments, streaming results, disk caches and export. Share MySQL/PostgreSQL/Doris catalog and metadata logic and refine Redis collection, field TTL and Stream readers while preserving raw values and uncertain-write protection.
- Use pure-black dark base canvases while retaining native controls and light appearance. Preserve per-window split identities, widths and visibility, and unify SSH navigation and settings.
- Source includes the validated iPhone/iPad multi-driver workspaces, migration, editor, native settings and physical-device validation project. Published downloads remain macOS packages; this release does not include App Store or TestFlight distribution.

## 验证与边界 / Validation and limits

合并后 Mac Debug 与通用 iOS 实体设备目标构建通过；MCP、SQL、SSH、设置、分栏与画布的 300 项回归通过，0 失败、0 跳过，原始 xcresult 独立核对一致。此前两台真机完整目标各 781 项通过；设置增量回归各 10 项通过，最终设置系统交互 iPad 2 项、iPhone 3 项通过。这些分阶段计数有重叠，不能相加当作独立测试总数。
Post-integration Mac Debug and generic physical-device iOS builds passed, along with 300 MCP/SQL/SSH/settings/split/canvas regressions and independently verified raw xcresult counts. Earlier full physical targets passed 781 tests per device, with 10 focused settings regressions each and final settings system checks of two on iPad and three on iPhone. These staged scopes overlap and must not be summed as unique coverage.

发布范围、恢复产物计划、更新归档与 SSH 分发脚本的 53 项检查也已通过。
Release-scope, recovery-artifact, update-archive and SSH-distribution script checks also passed all 53 tests.

正式产物由双架构流水线以 Release 配置构建、签名、打包，并执行独立 MCP、SSH 插件及六驱动原生加载和运行目录门禁后发布。权限矩阵包含程序化策略／替身，不等于同数量的外部数据库调用。文件提供商真实保存／云同步、全部 TLS/证书／服务器版本、真实弱网／内存压力、输入法候选和外接键盘组合仍有未覆盖范围；移动 Kafka、SSH、独立 MCP 和 MySQL 文件导入界面尚未移植。
Release artifacts are built and signed on both native architectures and gated on standalone MCP, SSH and six-driver loading/runtime checks before publication. Permission matrices include controlled policies/stubs rather than an equal number of external database calls. File-provider saves/cloud sync, all TLS/certificate/server variants, adverse-network/memory-pressure cases and keyboard/IME permutations are not exhaustively covered. Mobile Kafka, SSH, standalone MCP and the MySQL file-import UI remain unported.
