# QueryCraft MCP 0.1.4 (build 5)

## 中文

- 批量 SQL 默认返回精简计数和失败摘要，提供短期凭据分页读取明细，避免输出截断及为取结果重复执行写入；保留可选内联详细模式。
- 结构上下文展示驱动提供的表注释，按完整对象身份匹配，并支持表级分页、剩余数量和不完整表提示。
- 改善 SSH 传输大小限制的诊断，明确权限范围与 Kafka 消息检查能力。
- PostgreSQL 及其他驱动的事务内 DDL 限制保持原行为。Driver API 保持 5，SSH 插件身份不变；数据库驱动按各自累计改动独立发版，配套 Skill 独立更新为 1.0.2+3。

## English

- SQL batches return compact counts and failure summaries by default. Read bounded details from short-lived receipts without repeating writes, or explicitly request inline detailed results.
- Schema context includes verified table comments, matches complete object identities, and provides table pagination, remaining counts and incomplete-table guidance.
- Improve SSH transfer-limit diagnostics, permission discovery and bounded Kafka message inspection.
- Preserve existing DDL transaction restrictions. Driver API remains 5 and the SSH plugin identity is unchanged. Database drivers release independently according to their accumulated changes. Companion Skill instructions update independently to 1.0.2+3.
