# MCP 0.1.3 (4)

## 中文
- 新增基于可独立更新的 libssh2 插件的 SSH 工具，复用本机账号与独立授权。
- 支持命令、SFTP 文件管理、后台任务及传输进度与结果查询；任务与传输仅通过 MCP 使用。
- 支持本机 SSH Agent、最多四级跳板和逐跳失败诊断；凭据仍由本机安全存储管理。
- 新增 runtime_info，区分实际加载与已安装版本，并提示更新后重新连接客户端。
- 默认 stdio，远端无需安装 Python、Node 或专用代理；不会自动重放结果不确定的命令，不支持断点续传。

## English
- Adds SSH tools through the independently updated libssh2 plugin, sharing local accounts and explicit per-account grants.
- Supports commands, SFTP management, background tasks and retained transfer progress/results through MCP.
- Adds local SSH Agent, up to four jump hosts and per-hop diagnostics; credentials remain in local secure storage.
- Adds runtime_info to distinguish loaded and installed versions and indicate when clients must reconnect.
- Defaults to stdio with no remote Python, Node or agent installation. Uncertain commands are never automatically replayed; transfer resume is not supported.
