# QueryCraft MCP 0.1.0

## 中文

- MCP 作为可选独立组件下载安装，不再内置于主程序。
- 支持 stdio 与带认证的 Streamable HTTP，主程序退出后仍可运行。
- 提供六类已安装驱动的连接、结构、查询与相应原生能力；权限由服务端执行。
- 发行清单声明主程序、Driver API、存储、凭据及桌面联动接口的兼容要求。
- 使用固定启动入口与不可变版本目录，升级前完成签名、摘要、兼容性和协议自检，支持回退。
- 旧客户端路径保留；在设置中重新添加客户端后使用固定入口。

## English

- Install MCP as an optional independent component; the desktop application contains no MCP package.
- Use stdio or authenticated Streamable HTTP, including when the desktop application is closed.
- Discover authorized connections, inspect schemas and use the capabilities of the six installed driver families.
- Signed release records declare desktop, Driver API, storage, credential and desktop-bridge compatibility.
- A stable launcher selects immutable runtime versions after signature, checksum, compatibility and protocol checks. A previous version can be restored.
- Legacy client paths are retained. Update client registration in settings to use the stable launcher.
