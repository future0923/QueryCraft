# QueryCraft MCP 0.1.6 (7)

## 中文

- 独立原生 MCP 包及其 Feature、凭据助手和 Swift 兼容动态库使用 Apple Developer ID 签名、公证和 Hardened Runtime，保留 Library Validation。
- 凭据助手固定开发者团队和允许的调用者，保留已有共享 vault、并发锁及旧版目录。首次访问旧钥匙串项目可能要求本人授权。
- 最低主程序 0.1.16，Driver API 仍为 5。需配套使用新签名的七类驱动及 SSH；原有工具协议和数据库能力不变。

## English

- Sign and notarize the standalone native MCP package, Feature, credential helper and Swift compatibility libraries with Apple Developer ID and Hardened Runtime, retaining Library Validation.
- Pin the helper to the developer team and permitted callers while retaining shared vaults, concurrent locking and legacy directories. Older Keychain items may require user authorization.
- Require desktop 0.1.16 with Driver API 5 and the new signed driver/SSH packages. Existing tool protocols and database capabilities are unchanged.
