# QueryCraft MCP 0.1.5 (build 6)

## 中文

- 新增 Milvus 只读 Query、Get 与单查询 Search 工具，复用 Collection、schema 和结构上下文发现入口。
- 绑定授权数据库和准确 Collection，校验请求体中的同名身份，限制路径、分页、行数和响应字节，保留大整数主键、向量和距离。
- 修正限定数据库范围下的 Milvus 元数据连接选择，提供直接工具和延迟插件发现。
- 使用已有六类驱动提供的结构化诊断标识，区分可识别的数据库、认证、权限、连接和 TLS 失败，保留安全的原生数字码与 SQLSTATE。
- 最低主程序 0.1.15，Driver API 5。Milvus 驱动与配套 Skill 独立发布。

## English

- Add read-only Milvus Query, Get and single-query Search tools with existing Collection, schema and schema-context discovery.
- Bind authorized databases and exact Collections, validate body identities, and bound routes, pagination, rows and response bytes while retaining large primary keys, vectors and distances.
- Select the authorized database for scoped Milvus metadata connections and support direct and lazy plugin discovery.
- Use structured identifiers from existing database drivers to classify supported database, authentication, permission, connection and TLS failures, retaining safe native codes and SQLSTATE.
- Require desktop 0.1.15 with Driver API 5. The Milvus driver and companion Skill publish independently.
