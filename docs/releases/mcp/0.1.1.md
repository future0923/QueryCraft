# QueryCraft MCP 0.1.1

## 中文

- 与主程序共用签名验证的凭据助手及单一钥匙串保险库，减少逐连接重复授权。
- 统一密码新增、修改、清除及迁移行为，防止并发写入或旧迁移恢复已清除密码。
- 改善安装进度及兼容性反馈，旧运行时明确提示升级。
- 独立双架构组件，最低主程序 0.1.11；Driver API 5、存储/凭据/桌面接口版本保持 1。

## English

- Share the signature-validated credential helper and one Keychain vault with the desktop, reducing repeated per-connection authorization.
- Unify password creation, updates, clearing and migration, protecting concurrent writes and cleared credentials.
- Improve installation progress and compatibility feedback with explicit upgrade messages for older runtimes.
- Independently packaged for Intel and Apple Silicon; requires desktop 0.1.11. Driver API remains 5 and storage/credential/desktop APIs remain 1.
