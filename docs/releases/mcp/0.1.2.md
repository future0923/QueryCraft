# QueryCraft MCP 0.1.2

## 中文

- SDK、stdio/HTTP 和 NIO 传输移入独立运行包，动态共享同一 Feature 模块，避免主程序携带传输依赖及重复驱动类型。
- 保留权限上限、凭据助手、持久化策略及旧会话兼容；强化 JSON/工具边界与初始化握手回归。
- Dev 使用独立的 `QueryCraft Dev` / `querycraft-dev` 身份、注册归属、组件来源及 Skill 安装路径；未配置 Dev 来源时保留本地组件，不回退生产下载。
- Intel / Apple Silicon 独立组件，版本 0.1.2 (3)，最低主程序 0.1.12。Driver API 5，存储/凭据/桌面 API 1 均不变。

## English

- Move the SDK, stdio/HTTP and NIO transport into a standalone runtime that dynamically shares one Feature module, removing desktop transport dependencies and duplicate driver types.
- Preserve permission ceilings, credential helpers, policy storage and existing sessions; strengthen JSON/tool boundaries and initialization handshake regressions.
- Use separate `QueryCraft Dev` / `querycraft-dev` identities, registration ownership, feeds and installed Skill paths. Without a configured development feed, keep local components and reject production-download fallback.
- Native Intel and Apple Silicon components, version 0.1.2 (3), minimum desktop 0.1.12. Driver API remains 5; storage, credential and desktop APIs remain 1.
