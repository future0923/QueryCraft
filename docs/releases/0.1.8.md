# QueryCraft 0.1.8

## 本次更新

- SQL 表格编辑新增紧凑的日期与时间编辑器：年月日、时分秒分别支持直接输入和上下调节。
- 日期、时间、日期时间字段按类型显示对应编辑行，支持 `TIME` 类型。
- 日期编辑弹窗改为居中的玻璃材质布局，提供“现在 / NULL / 应用”三个操作按钮。
- SQL 表格与查询结果编辑统一接入日期编辑器，并在结果刷新或切换对象时正确结束过期编辑状态。
- 增加 SQL 日期编辑、时区、精度和别名字段元数据测试。
- 因 SQL 驱动元数据链路更新，MySQL、PostgreSQL、Doris 驱动升级至 `1.0.4 (5)`。

## What's New

- Added a compact SQL date and time editor with direct input and stepper controls for year, month, day, hour, minute, and second.
- Date-only, time-only, and date-time columns now show only the controls relevant to their SQL type, including `TIME` columns.
- Reworked the editor popover with a centered glass-style layout and consistent Now, NULL, and Apply actions.
- Unified date editing across SQL table cells and query result cells, including cleanup when results or selected objects change.
- Added coverage for SQL date editing, timezone handling, precision, and aliased column metadata.
- MySQL, PostgreSQL, and Doris drivers were bumped to `1.0.4 (5)` for the updated SQL metadata path.
