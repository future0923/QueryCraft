# QueryCraft Skill 1.0.0

## 中文

- Skill 作为独立可选资源下载安装，与 MCP 和主程序分别版本管理。
- 清单声明所需 MCP 版本范围；不兼容时保留已有安装。
- 支持 Shared、Codex、Claude Code 目录，提供六类驱动工作流指导。
- 更新及卸载保留用户本地修改，拒绝通过符号链接替换其他文件。

## English

- Install the optional Skill independently, with its own release version and compatible MCP version range.
- Keep the existing installation when compatibility checks fail.
- Support Shared, Codex and Claude Code destinations and guidance for all six driver families.
- Preserve local modifications during updates and removal; refuse symbolic-link replacement.
