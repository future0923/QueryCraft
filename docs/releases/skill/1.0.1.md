# QueryCraft Skill 1.0.1 (2)

## 中文
- 更新数据库、对象、连接与分组的权限继承说明；完整访问仍遵守对象范围、工具开关、驱动能力和操作确认。
- 说明 SQL 上下文函数、跨库读写、DDL、Redis 逻辑库以及 Elasticsearch/Kafka 的真实边界与错误恢复。
- 增加 SSH/Shell 参考，区分保存脚本与执行命令，并说明独立组件更新后已有会话的重连判断。

## English
- Documents object/database, connection and group permission inheritance. Full access retains object scopes, tool switches, driver capabilities and operation confirmations.
- Clarifies context functions, cross-database access, DDL, Redis logical databases, Elasticsearch/Kafka boundaries and error recovery.
- Adds SSH/Shell guidance, separates saving scripts from executing commands, and explains when existing sessions must reconnect after a component update.

此版要求 MCP 至少 0.1.3、主程序至少 0.1.12，以匹配新的权限继承语义。
Requires MCP 0.1.3 and desktop 0.1.12 or later for the documented permission semantics.
