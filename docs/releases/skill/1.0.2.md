# QueryCraft Skill 1.0.2 (build 3)

## 中文

- 批量 SQL 优先检查汇总计数、失败和事务状态，只在需要时通过短期凭据读取明细，避免重复执行写入或拉取全部成功记录。
- 补充结构上下文的分页、不完整表和真实表注释指引，兼容旧服务器的内联结果与实际工具 schema。
- 权限边界、事务内 DDL 限制和六类驱动行为保持原样。

## English

- Inspect batch counts, failures and transaction status first; retrieve only needed details through short-lived receipts without repeating writes or fetching every successful record.
- Explain schema pagination, incomplete tables and verified comments while respecting older inline-result servers and the actual tool schema.
- Preserve authorization boundaries, existing DDL transaction restrictions and all six driver behaviors.
