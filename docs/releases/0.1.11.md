# QueryCraft 0.1.11

## 本次更新

- 新增原生数据传输工作台，支持可复用任务、结构与数据复制、逐表过滤、Upsert、后台执行和取消回滚。
- MySQL LOAD DATA 与 PostgreSQL COPY 原生批量通道实现有界流式传输；四个方向千万行全量校验通过，实测耗时 45.75～121.81 秒，测试进程采样峰值内存 26.34～40.62 MiB。
- 新增 MySQL 结构对比与同步，支持差异检查、SQL 预览和部署。
- 主程序与 MCP 统一凭据授权，减少重复钥匙串授权；改善 MCP 安装进度和兼容性反馈。
- 改善深色编辑器背景及数据传输界面，精简中英文 README 为产品能力与实测性能。

## What's New

- Added a native data-transfer workbench with reusable tasks, structure/data copying, per-table filters, Upsert, background execution and cancellation rollback.
- Bounded MySQL LOAD DATA and PostgreSQL COPY pipelines passed full-field verification in four 10-million-row transfers: 45.75–121.81 seconds and 26.34–40.62 MiB sampled peak RSS of the test process.
- Added MySQL schema comparison and synchronization with difference review, SQL preview and deployment.
- Unified desktop/MCP credential authorization to reduce repeated Keychain prompts, with improved MCP installation progress and compatibility feedback.
- Improved dark editor backgrounds and transfer presentation; simplified both READMEs around capabilities and measured performance.

The three new driver packages require desktop 0.1.11, preventing older hosts from loading missing symbols. MariaDBTransportV2 supports independent MySQL/Doris upgrades. MCP 0.1.1 requires desktop 0.1.11; the unchanged Skill supports MCP 0.1.x.

## 验证 / Validation

本地 Intel 原生通道通过 45 项回归、四方向实库边界、百万行追加与 Upsert、四方向千万行及六项取消回滚，逐字段校验零差异。六类驱动加载、关闭 LOCAL 与 TEMP 权限不足时回退、三组 Doris/新旧 MySQL 混装均已验证。基准为本地 Docker 的五列混合类型、每批 1000 行、各容器 4 CPU / 2 GiB；耗时包含执行复核及提交，不包含夹具生成与结果校验；RSS 按秒采样，不代表完整 App 总内存，性能依赖硬件、表结构和网络。
Doris 已做来源小样本实库验证，未做千万行；MariaDB 服务端未实测。Redis/Elasticsearch/Kafka 不适用本次关系表通道。未进行物理鼠标/键盘验收。

Local Intel validation covers 45 native-transfer regressions, four-direction live edge cases, million-row append/Upsert, four 10-million-row transfers and six cancellation/rollback cases with no field differences. Six-driver loading, disabled LOCAL, denied TEMP and three Doris/mixed-version combinations passed. Measurements use five mixed-type columns, 1,000-row batches and local Docker containers capped at 4 CPUs / 2 GiB each; execution checks and commit are included, fixture generation and final verification excluded. RSS is sampled once per second for the test harness, not the whole application.
Doris received live small-sample source testing, not a 10-million-row benchmark; a MariaDB server was not tested. Redis/Elasticsearch/Kafka are outside the relational transfer scope. No physical-input UI acceptance is claimed.
