# QueryCraft 0.1.15

## 中文

- 新增 Milvus REST v2 驱动，支持数据库与 Collection 目录、字段结构、主键与向量维度，以及分页实体浏览、JSON 和向量预览。
- MCP 新增 Milvus Query、按 ID Get 和单查询向量 Search，保留大整数主键精度、距离和原生响应。数据库授权、Collection 绑定、只读路径、分页与结果预算沿用公共权限链路。
- SQL、筛选、数据网格等快捷键按实际焦点生效，恢复编辑器与单元格的原生光标移动。表数据页与 SQL 结果页支持多选同列统一修改及原生粘贴。
- 表头标题选择列，独立排序菜单提供数据库排序与当前页排序，并显示当前方向。改善大型对象目录下的表格交互性能。
- macOS 深色基础背景统一使用柔和深灰，空字段注释不再占用表头高度，连接加载保留稳定内容框架。
- MCP 保留六类已有数据库驱动提供的结构化错误标识，区分可识别的认证、权限、数据库、网络及 TLS 失败，并限制服务端错误内容的暴露。

## English

- Add a Milvus REST v2 driver with database and Collection discovery, field schemas, primary-key and vector-dimension metadata, paginated entity browsing, and JSON/vector previews.
- Add MCP Milvus Query, Get by ID and single-query Search, preserving large primary keys, distances and native responses. Reuse database authorization with bound Collection identities, read-only routes, pagination and response budgets.
- Scope SQL, filter and grid shortcuts to the actual focused control, restoring native cursor movement in editors and cells. Support multi-selection column editing and native paste in table data and SQL results.
- Use header titles for column selection and a separate menu for database and current-page sorting, with direction feedback. Improve grid interaction with large object directories.
- Use a softer dark-gray macOS base background, remove empty comment rows from headers, and retain stable page structure during connection loading.
- Preserve structured native error identifiers from all six existing database drivers so MCP can classify supported authentication, permission, database, network and TLS failures while limiting server-message exposure.

## 验证与边界 / Validation and limits

本轮功能验证已有 macOS 主程序、独立 MCP 和 Milvus 动态产品编译，42 项 MCP/Milvus 回归，搬迁签名包的 stdio/HTTP 与七驱动加载。阿里云 default 数据库的 Collection 目录、23 字段 schema、Query、Get 和 1024 维 COSINE Search 实库检查通过。六类已有驱动的错误诊断单测、签名打包和协议 loopback 检查已通过。
Feature validation includes native desktop, standalone MCP and Milvus dynamic-product builds, 42 MCP/Milvus regressions, relocated signed-package stdio/HTTP and seven-driver loading. The Alibaba Cloud default database passed Collection discovery, a 23-field schema, Query, Get and 1024-dimensional COSINE Search. Existing-driver diagnostic tests, signed packages and protocol loopback checks also passed.

发版前新增 140 项核心/MCP 回归、60 项工作区回归、7 项独立协议测试与 66 项发布脚本检查全部通过，0 失败、0 跳过。正式 Intel 与 Apple Silicon 产物由 Actions 原生构建、签名和加载门禁验证后发布。
Fresh pre-release checks passed 140 core/MCP regressions, 60 workspace regressions, seven standalone protocol tests and 66 release-script checks, with no failures or skips. Final Intel and Apple Silicon artifacts are published after native Actions builds, signing and loading gates pass.

Milvus v1 提供只读浏览和 MCP 读取，Search 每次一个查询向量。通用 SQL 编辑、精确总数及事务能力按驱动真实能力处理。现有六类驱动的实库、全部认证/TLS 组合未穷尽验证。移动端共享源码已接入 Milvus，完整移动构建及设备验收另行进行。本次发布 macOS 下载包。
Milvus v1 provides read-only browsing and MCP reads, with one query vector per Search call. SQL editing, exact counts and transactions follow actual driver capabilities. Live checks of the existing six services and every authentication/TLS combination are not exhaustive. Shared mobile sources include Milvus, with complete mobile builds and device acceptance tracked separately. This release distributes macOS download packages.
