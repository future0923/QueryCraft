# QueryCraft 0.1.7

## 本次更新

- 新增原生 Kafka 插件，支持 Topic 浏览与管理、消息读取与发送、消费组查看及 JSON 消息表格展示；同步发布 Intel 与 Apple Silicon Kafka 驱动。
- SQL 批量执行新增消息与摘要视图，展示执行 SQL、返回或影响行数、耗时及结果数量限制；执行期间保持消息页签并跟随执行进度滚动。单条查询直接展示表格，更新、删除等无查询结果的语句展示执行消息。
- SQL 预览支持语法高亮、自动换行、窗口缩放、字号调整与复制；双击语句或使用悬停时出现的放大按钮即可查看完整内容。
- 可编辑的查询结果支持删除行和批量编辑单元格，配合变更预览与提交操作完成修改。
- 修复 SQL 自动补全上下文混用、默认选中项未重置和列信息加载失败后无法重试的问题，并完善 DESC 语句识别。
- 修复重新构建或升级应用后反复要求钥匙串授权的问题：连接密码由固定安装的 QueryCraft Credentials 辅助程序访问，仍保存在 macOS 钥匙串中。已有连接首次迁移时可能需要为该辅助程序选择一次“始终允许”，后续主应用升级将保留授权。
- 同步更新 MySQL、PostgreSQL、Doris、Redis、Elasticsearch 和 Kafka 的 Intel 与 Apple Silicon 驱动。

## What's New

- Added a native Kafka plugin with topic browsing and management, message reading and producing, consumer group inspection, and JSON message tables. Kafka drivers are available for Intel and Apple Silicon.
- Added messages and summaries for SQL batch execution, including executed SQL, returned or affected rows, elapsed time, and result row limits. Execution stays on the messages tab and scrolls with progress. A single query opens its result table directly; statements without query results show execution messages.
- SQL previews support syntax highlighting, line wrapping, resizable windows, font size controls, and copying. Double-click a statement or use its hover-only expand button to view the complete SQL.
- Editable query results now support row deletion and bulk cell editing, with change previews and commit actions.
- Fixed SQL completion context isolation, default selection reset, and retries after column metadata loading failures, and improved DESC statement recognition.
- Fixed repeated Keychain authorization prompts after rebuilding or upgrading the app. A persistently installed QueryCraft Credentials helper accesses connection passwords, which remain in the macOS Keychain. Existing connections may require selecting Always Allow once for the helper during migration; later main app upgrades preserve that authorization.
- Updated MySQL, PostgreSQL, Doris, Redis, Elasticsearch, and Kafka drivers for Intel and Apple Silicon.
