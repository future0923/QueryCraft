# SSH plugin 0.9.0 (11)

## 中文
- 大量终端输出按时间预算处理，合并滚动条刷新；阅读历史时保持滚动位置。
- 支持触控板细小滚动、全屏程序鼠标滚轮报告及备用屏幕方向键回退。
- 加入可持续交互的 PTY 终端通道，支持双向输入输出、窗口缩放、Ctrl-C 和全屏程序。
- SwiftTerm 1.10.1 显示组件随 SSH 插件分发，主程序不再内置或链接 SwiftTerm。
- 终端显示组件独立签名并按需加载；MCP 使用命令或文件能力时不加载显示组件。
- 基础 ABI 仍为 1；新增 terminal 与 terminal-renderer 可选接口 1。旧插件的 MCP 能力保留，使用终端需要升级插件及兼容主程序。
- 更新保留原版本；已经加载终端显示组件的应用需要重启以使用新版。服务器无需安装额外软件。

## English
- Budget terminal output processing and coalesce scrollbar updates; keep scrollback anchored during incoming output.
- Support precise trackpad deltas, application mouse wheel reports and cursor-key fallback in alternate screens.
- Persistent interactive PTY channels support duplex input/output, resize, Ctrl-C and full-screen programs.
- SwiftTerm 1.10.1 ships inside the SSH plugin; the host app no longer embeds or links SwiftTerm.
- The separately signed renderer loads only when needed. MCP commands and file operations do not load it.
- Base ABI remains 1, with optional terminal and terminal-renderer interface 1. Older plugins retain their MCP functionality; terminals require the updated plugin and a compatible host.
- Updates retain the previous version. Restart an app that has already loaded the renderer to use an updated renderer. No additional server software is required.
