# SSH plugin 0.9.1 (12)

## 中文

- SSH 插件、依赖及可选终端显示组件改用 Apple Developer ID 签名、可信时间戳和 Hardened Runtime，分发 ZIP 提交 Apple 公证。
- 最低主程序 0.1.16，保留基础 ABI 1 及 terminal/terminal-renderer 接口 1，SSH 功能与服务器要求不变。
- 保留旧安装版本，已加载插件的进程需要重启或重连后使用新版。

## English

- Sign the SSH plugin, dependencies and optional terminal renderer with Apple Developer ID, trusted timestamps and Hardened Runtime; submit distribution ZIPs for Apple notarization.
- Require desktop 0.1.16, retaining base ABI 1 and terminal/terminal-renderer interface 1. SSH behavior and server requirements are unchanged.
- Retain previous installed versions. Restart or reconnect processes that already loaded an older plugin to use the update.
