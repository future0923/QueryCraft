# SSH plugin 0.7.0 (7)

## 中文
- 首次独立分发 SSH 插件，提供 Intel 与 Apple Silicon 原生包，静态包含 libssh2 1.11.1 和 OpenSSL 3.6.3。
- 基础 ABI 1，包含文件、文件管理、连接池、进度、跳板与诊断扩展 1。
- 支持密码、私钥和本机 SSH Agent；逐跳校验主机指纹，最多四个跳板，不转发 Agent。
- 安装包与兼容信息分别校验固定证书、SHA-256 和 Ed25519 签名。更新保存不可变旧版本；已有 MCP 会话需重连才加载新插件。
- 独立于六类数据库驱动更新，不改变 Driver API 5。无远端新增运行时，不自动重试命令，不支持断点续传。

## English
- First independent SSH plugin distribution, with native Intel and Apple Silicon packages bundling libssh2 1.11.1 and OpenSSL 3.6.3 statically.
- Base ABI 1 with file, file-management, pool, progress, route and diagnostic extension 1.
- Password, private-key and local SSH Agent authentication, per-hop host-key pinning and up to four jump hosts; no agent forwarding.
- Packages and compatibility metadata are checked with the pinned signing certificate, SHA-256 and Ed25519 signatures. Updates retain immutable old versions; reconnect existing MCP clients to load the update.
- Independent from the six database drivers; Driver API 5 is unchanged. No additional remote runtime, automatic command replay or transfer resume.
