# QueryCraft 0.1.14

## 中文

- 修复 SQL 编辑器多行删除后的布局与行坐标，保留输入、撤销和选区行为；连接目录加载完成后再显示可用连接类型。
- MySQL 与 Doris 的长时间 SQL 不再被固定 10 秒读写超时中断，保留连接超时与手动取消。
- MCP 批量 SQL 默认返回精简计数、失败摘要和事务状态，通过短期凭据分页读取明细，避免输出截断或为取结果重复执行写入。结构上下文增加真实表注释、表级分页及不完整表提示。
- MCP 增加 SSH 有效权限说明与结构化拒绝原因，改善传输大小限制诊断；Kafka 支持受限消息搜索、时间窗口、完整消息匹配与读取隔离配置，完善消费组偏移量信息。
- 配套 Skill 更新批量结果、结构分页、SSH 与 Kafka 使用指引；权限边界及事务内 DDL 限制保持原行为。

## English

- Fix SQL editor layout and line coordinates after multiline deletion while retaining input, undo and selection behavior. Show available connection types after catalog loading completes.
- Keep long-running MySQL and Doris queries from being interrupted by a fixed ten-second I/O timeout, while retaining connection timeouts and manual cancellation.
- MCP SQL batches return compact counts, failure summaries and transaction state by default. Retrieve details through short-lived paginated receipts without repeating writes. Schema context adds verified table comments, table pagination and incomplete-table guidance.
- Add effective SSH permission discovery and structured denial reasons, and improve transfer-limit diagnostics. Kafka gains bounded message search, time windows, complete-message matching and configurable read isolation, with improved consumer-group offset information.
- Update companion Skill guidance for batch results, schema pagination, SSH and Kafka while preserving authorization boundaries and existing DDL transaction restrictions.

MySQL 与 Doris 共享 transport，必须成对发布并验证单独加载、同时加载和独立升级兼容性。Kafka 新包依赖主程序 0.1.14 提供的可选协议符号；保留历史版本供旧主程序选择。主程序不内置独立 MCP、Skill 或数据库驱动包。
MySQL and Doris share the transport and are released together with separate, simultaneous and independent-upgrade loading checks. The new Kafka package requires optional protocol symbols introduced in desktop 0.1.14; historical releases remain available to older clients. The desktop does not embed standalone MCP, Skill or database driver packages.

## 验证与边界 / Validation and limits

发版前新增本机检查：macOS x86_64 Debug 主程序编译通过；119 项核心回归全部通过，0 失败、0 跳过；Kafka 驱动回归 60 项通过、0 失败，14 项因缺少真实 broker 环境跳过；发布范围、产物恢复、SSH 分发和更新归档的 61 项脚本检查全部通过。
Fresh local release checks passed: the macOS x86_64 Debug desktop build, all 119 selected core regressions (no failures or skips), 60 Kafka driver tests (no failures, 14 real-broker integration skips), and all 61 release-scope, artifact-recovery, SSH-distribution and update-archive script checks.

累计功能验证记录见 `docs/MCP_BATCH_SCHEMA_VERIFICATION.md`：本机主程序与独立 MCP 编译、批量与结构上下文、权限与会话、搬迁签名 MCP 的 stdio/HTTP 和六类 API 5 驱动加载均已验证。既有 SQL loopback 验收覆盖超过 10 秒等待及手动取消，既有 Kafka 验收覆盖隔离配置、搜索预算与原生驱动加载。各阶段测试有重叠，不累加为独立用例总数。
Accumulated feature validation is recorded in `docs/MCP_BATCH_SCHEMA_VERIFICATION.md`: local desktop/MCP builds, batch/schema behavior, permissions and sessions, relocated signed MCP stdio/HTTP and loading of all six API 5 drivers passed. Earlier SQL loopback acceptance covers waits beyond ten seconds and manual cancellation; Kafka acceptance covers isolation configuration, search budgets and native driver loading. Staged test counts overlap and are not summed as unique coverage.

本机三类动态驱动独立构建与打包通过。新版 MySQL/Doris 包的长查询、流式等待、手动取消及取消后连接复用通过；Kafka 新包原生能力检查通过。新版独立 MCP 的搬迁签名、运行依赖、stdio/HTTP、六类驱动加载、MySQL/Doris 单独加载与双向新旧包混合升级验证均通过。驱动使用与正式 CI 相同的 ad-hoc 签名策略，主程序/MCP 使用固定证书。
All three native driver builds and packages passed. New MySQL/Doris packages passed long-query, streaming-wait, manual-cancellation and post-cancellation reuse checks; the Kafka package passed native capability checks. The new standalone MCP passed relocated signature/dependency, stdio/HTTP, six-driver loading, separate MySQL/Doris loading and both mixed old/new transport upgrade combinations. Drivers follow the official CI ad-hoc signing policy; desktop/MCP use the pinned certificate.

正式双架构产物由发布工作流构建、签名及验证；仅在对应门禁通过后发布。实库时间戳索引、Kafka 已提交/已中止事务可见性、全部 TLS/认证组合及所有数据库服务版本未穷尽验证。本次为 macOS 下载发行，不包含 App Store/TestFlight 包。
Final native artifacts are built, signed and validated by the release workflow and published only after the corresponding gates pass. Real-broker timestamp indexing, Kafka committed/aborted transaction visibility, all TLS/authentication combinations and all database server versions are not exhaustively verified. This is a macOS download release and does not include App Store/TestFlight packages.
