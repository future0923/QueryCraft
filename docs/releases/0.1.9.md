# QueryCraft 0.1.9

## 本次更新

- 重做 SQL 片段补全的占位符状态显示：当前输入位置使用清晰的描边和强调底色，其他待填写位置使用淡色提示，亮色和暗色主题都能区分当前编辑位置。
- 修复 SQL 片段补全在输入、退格、清空后重填、配对引号、中文输入法、撤销和重做后跳转位置丢失的问题。
- 修复 `Tab`、`Shift-Tab` 在补全列表和输入法组合输入下偶发失效的问题；支持循环回到上一项，完成最后一项后退出片段编辑。
- 增加可持久化的 SQL 片段设置，并支持复制行和内容页签快捷键。
- SQL 补全结果支持显示字段与表注释，相关元数据链路升级到 Driver API 5。
- SQL 语法资源在 Swift Package 和 Xcode 环境下统一正确加载。
- 同步发布 Driver API 5 的 MySQL、PostgreSQL、Doris、Redis、Elasticsearch 和 Kafka Intel 与 Apple Silicon 驱动。

## What's New

- Reworked SQL snippet placeholder styling: the current editing position now uses a clear outline and accent fill, while other pending positions use a subtle hint fill in both light and dark themes.
- Fixed snippet navigation losing its placeholder ranges after typing, backspacing, clearing and retyping, paired quotes, Chinese input method composition, undo, or redo.
- Fixed intermittent `Tab` and `Shift-Tab` navigation failures while the completion list or an input method is active. Navigation now wraps backward and exits cleanly after the final placeholder.
- Added persisted SQL snippet settings, duplicate-line support, and content-tab keyboard shortcuts.
- SQL completion results can show field and table comments; the metadata path now uses Driver API 5.
- Fixed SQL grammar resources loading consistently in both Swift Package and Xcode environments.
- Published Driver API 5 MySQL, PostgreSQL, Doris, Redis, Elasticsearch, and Kafka drivers for Intel and Apple Silicon.
