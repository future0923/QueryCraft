# QueryCraft 0.1.10

## 本次更新

- 新增独立 MCP 组件：支持本地 stdio 和带认证的 Streamable HTTP，QueryCraft 退出后仍可访问已授权数据库。
- 新增原生 macOS MCP 设置、连接/数据库/工具权限和调用摘要；支持客户端配置一键添加与移除，优化首次加载、权限切换和记录滚动。
- MCP 程序与可选 QueryCraft Skill 分别下载安装、更新及卸载，提供版本兼容检查、签名和摘要验证、原子切换与回退；保留用户授权和 Skill 本地修改。主程序不内置这两个安装包。
- 改善 Codex 的 MCP 初始化兼容性，提供限量查询、结构上下文、长字段展开、事务会话及六类已安装驱动的相应工具。
- 新增编辑器颜色自定义，并改善 SQL/JSON 语法高亮、增量解析及不同编辑场景下的颜色一致性。
- 新增表数据导出和流式导入，支持 CSV、JSON、SQL 和 XLSX，以及导出选项、批量写入和取消处理。
- MySQL、Doris 改用共享动态 MariaDB transport，避免同时加载驱动时重复注册类型；同步发布两者 1.0.6（7）。Driver API 保持 5。
- PostgreSQL 1.0.5（6）、Redis/Elasticsearch/Kafka 1.0.1（2）保持不变，不重新发布。

## What's New

- Added an independent MCP component with local stdio and authenticated Streamable HTTP. Authorized database tools continue working after QueryCraft exits.
- Added native macOS MCP settings, connection/database/tool permissions and bounded call summaries, with one-click client registration/removal and smoother loading, permission switching and history scrolling.
- Install, update and remove MCP and the optional QueryCraft Skill independently. Compatibility checks, signatures, checksums, atomic activation and rollback preserve authorization and local Skill edits. Neither installation payload is embedded in the desktop application.
- Improved Codex MCP initialization compatibility. Tools cover bounded queries, schema context, long-cell expansion, transaction sessions and the capabilities of six installed driver families.
- Added editor color customization and improved SQL/JSON highlighting, incremental parsing and color consistency across editing workflows.
- Added table-data export and streaming import for CSV, JSON, SQL and XLSX, including export options, batched writes and cancellation.
- MySQL and Doris now share a dynamic MariaDB transport to avoid duplicate runtime type registration. Both drivers advance to 1.0.6 (7); Driver API remains 5.
- PostgreSQL 1.0.5 (6) and Redis/Elasticsearch/Kafka 1.0.1 (2) are unchanged and are not republished.

## Release scope and validation

Application: 0.1.10 (20). MCP: 0.1.0 (1). Skill: 1.0.0 (1).
MCP and Skill require QueryCraft 0.1.10 or later and Driver API 5; Skill requires MCP 0.1.x.
MySQL/Doris: publish both x86_64 and arm64. Other four driver families: retain the compatible online API 5 releases.

Local Intel validation passed: Debug build, 131 MCP/settings/SQL regressions, 14 release-scope tests, all LicenseServer Go packages, signed component lifecycle/rollback, standalone stdio/HTTP and six-driver loading. Native settings were rendered offscreen; physical-input interaction and an actual OS reboot are not claimed.
The release workflow builds native Intel/Apple Silicon installers, a Universal Sparkle archive, independently signed MCP/Skill packages and the two affected drivers. Online catalogs and downloadable artifacts must pass publication checks before release completion.
